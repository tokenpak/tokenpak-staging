# TokenPak v1.10.0 Release Log

## Scope

Minor release that graduates TokenPak Dispatch into the released `pip install
tokenpak` package, fixes the base-install FastAPI import requirement, updates
the proxy version probe to derive the expected version from the installed
package, ships missing package data files, and points Free-tier upgrade guidance
at `https://tokenpak.ai/pro`.

This log was created during release closeout repair on 2026-06-29. It records
the observed publication state and the public-surface truth gap found after the
release. It must not be read as evidence that a release log existed before the
tag or that closeout was clean at publication time.
